Everything you need

A batteries-included engine for AI agent orchestration in Rails.

🗄️

ActiveRecord Integration

Persist crews, agents, tasks, and executions directly in your database.

⚙️

Background Jobs

Runs through ActiveJob — works with Sidekiq, Resque, Delayed Job, or any adapter.

🏗️

Rails Generators

Scaffold new crews and agents from the command line in seconds.

📊

Web Dashboard

Monitor executions, view logs, and manage crews through a built-in UI.

🤖

Multi-LLM Support

OpenAI, Anthropic Claude, Google Gemini, Azure OpenAI, Ollama, AWS Bedrock, Snowflake Cortex, and any OpenAI-compatible endpoint.

🧰

Rails-Specific Tools

Pre-built tools for ActiveRecord, ActionMailer, the Rails cache, and more.

What's new 0.4 – 0.11

rcrewai features through 0.9, surfaced through ActiveRecord, on rcrewai 0.11.

Agent intelligence

Reasoning passes, per-agent LLM overrides, rate limiting, context-window trimming, and cognitive memory.

Task output

Structured output schemas, guardrails, file output, and multimodal image attachments.

Crew orchestration

before/after kickoff hooks, planning, the consensual process, and batch execution.

Knowledge (RAG)

String, file, PDF, CSV, and URL sources attached to agents or crews.

Flows

Persist and resume rcrewai Flow state through the database; track each run.

Cognitive memory

Semantic recall with a pluggable embedder and SQLite-backed store.

Observation engine

Span-level traces of every run, with timings, tokens, cost, and a live view.

Checkpointing

Resume an interrupted run without re-running the tasks it already finished.

Interceptors and providers

Hooks around every LLM request, plus Bedrock, Snowflake, and OpenAI-compatible endpoints.

Concurrent tool calls

A turn's tool calls run in parallel, with a per-agent opt-out.
